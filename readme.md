### 누구신가요?
다시 개발자로 복귀를 꿈꾸는 이중훈입니다~ 
### 왜 만들었나요?
개발을 하지 않고 쉬는 동안 많은 부분을 잊어 먹었고 새로운 것이 많이 생겼습니다. 포트폴리오를 만들면서 새로운 기술을 사용해 보고 잊어먹은 지식을 다시 찾는 과정을 진행하고자 포트폴리오를 만들게 되었어요.

### 무엇을 사용해 만드셨나요?
채용공고에서 자주 나오는 기술을 최대한 사용해 보려고 했어요.
UI는 React를 사용하였고, 스타일링은 tailwindcss를 사용해 보았습니다.
(UI 라이브러리로는 HeroUI를 활용했어요~)
